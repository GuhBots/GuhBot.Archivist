# Documentation Map

The repository's documents are listed below. [Documentation](documentation.md) explains where new documents belong and the conventions they follow.

## Repository Conventions

* [Repository Overview](../README.md) explains Archivist, its layout, and development commands.
* [Contributing](../CONTRIBUTING.md) covers branches, pull requests, verification, and review.
* [Repository Instructions](../AGENTS.md) provides instructions for AI assistants.
* [Coding Style](coding-style.md) covers code, prose, Markdown, diagrams, and language-specific extensions.
* [Documentation](documentation.md) covers document placement, design documents, and proposals.
* [Glossary](glossary.md) defines shared terms and acronyms.
* [Dev Container](../.devcontainer/README.md) covers the shared development environment and how to customize it.

## Guides

* [Guide Index](guides/README.md) lists the included guides.
* [Self-Hosting](guides/self-hosting.md) covers running Archivist on a server and on your own domain with a Cloudflare Tunnel.
* [Connecting the Bot](guides/connecting-the-bot.md) covers the Discord bot's service token and address.
* [Moving From the Bot](guides/moving-from-the-bot.md) covers moving archives and settings out of the bot.
* [Releasing](guides/releasing.md) covers version numbers, releases, and published images.
* [Template Usage](guides/template-usage.md) covers the template this repository started from.

## Design

* [Bot API](design/bot-api.md) is the contract between the service and the Discord bot.

The product specification is the [Archivist plan](https://github.com/GuhBots/GuhBot.Discord/blob/feat/archivist/docs/proposals/ARCHIVIST-PLAN.md) in the GuhBot.Discord repository. Component documents are linked from each workspace's README.
