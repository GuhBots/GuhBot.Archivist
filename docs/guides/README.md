# Guides

Guides explain tasks, concepts, and workflows. Repository-wide guides live here. Guides for a single component belong beside that component.

## Available Guides

* [Self-Hosting](self-hosting.md) explains how to run Archivist on a Raspberry Pi, laptop, or server, and how to put it on your own domain with a Cloudflare Tunnel.
* [Connecting the Bot](connecting-the-bot.md) explains the Discord bot's service token, its address, and how to change or revoke them.
* [Moving From the Bot](moving-from-the-bot.md) explains how to move archives and their settings from the bot to this service.
* [Releasing](releasing.md) explains version numbers, how to create a release, and which images are published.
* [Template Usage](template-usage.md) explains how the template this repository started from is adopted and extended.

For shared rules and other documents, see the [Documentation Map](../README.md).
