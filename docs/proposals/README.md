# Proposals

This directory contains plans for changes under discussion before implementation, kept as decision records afterward. Follow the repository's [documentation conventions](../documentation.md#proposals) when updating a proposal and its decision status.

* [Archivist Plan](ARCHIVIST-PLAN.md) records Archivist's accepted requirements, the standalone service migration, interface contracts, milestones, and verification criteria. It moved here from GuhBot.Discord on 2026-11-24.
* `assets/` holds the plan's supporting images, such as the owner's layout sketch.
